# Contributing to elitea-capstone-project

Thank you for your interest in contributing. This document provides a minimal contribution guide to help maintainers and contributors collaborate efficiently.

- Fork the repository and create a feature branch from main: git checkout -b feature/your-feature
- Follow coding standards: Java 17, Spring Boot conventions, use meaningful commit messages.
- Run tests locally: mvn test
- Submit a pull request describing the change, references to issues, and testing steps.

Code of Conduct
Be respectful and constructive. Any abusive behaviour will not be tolerated.
